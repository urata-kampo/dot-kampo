# ドット漢方堂

ファミコン風ドット絵の漢方薬局けいえいシミュレーション。

**遊ぶ：** https://urata-kampo.github.io/dot-kampo/

スマホで開いて「ホーム画面に追加」すると、アプリのように全画面・オフラインで遊べます。

- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：「アプリをインストール」または「ホーム画面に追加」

> ゲーム内の情報は学習・娯楽用に簡略化したものです。実際の服用の判断には使わず、医師・薬剤師にご相談ください。

## 更新のしかた（GitHub Pages）

1. このリポジトリの画面で「Add file」→「Upload files」
2. 新しいファイルをドラッグして「Commit changes」（同じ名前のファイルは上書きされます）
3. 1〜3分で https://urata-kampo.github.io/dot-kampo/ に反映されます
4. アイコン・フォントなどを差し替えたときは、`sw.js` の `VERSION` を1つ上げる（例：`"v2"` → `"v3"`）
   ※上げないと、遊んでいる人の端末に古いファイルが残ります

## 公開リポジトリに置かないもの

鍵ファイル（credentials.json など）、`.env`、作業用の素材や個人情報は置かないでください。
